# Qwen2.5-1.5B GPU 测试结果

## 2026-04-28：CPU WALT 不锁频下的 `tg128 r=3` 与 `pp512` Sweep

### 测试配置

- 设备：`192.168.1.113:42977`
- 模型：`/data/local/tmp/restart-static-switch-validation/models/Qwen2.5-1.5B-AoT/ggml/weights.gguf`
- 后端：`GPUOpenCL`，`-ngl 99 -dev GPUOpenCL`
- 线程绑定：`taskset 80 -t 1`
- CPU 背景策略：`walt`，不手动锁频；本次设备实际限制为 `policy0=384000-1996800`，`policy6=1017600-2649600`
- `tg128` 测试形态：`-p 0 -n 128 -c 1024 -r 3`
- `pp512` 测试形态：`-p 512 -n 0 -c 1024`
- `pp512` round 设置：高频 `1100-832 MHz` 使用 `r=25`，中频 `734-443 MHz` 使用 `r=15`，低频 `389-160 MHz` 使用 `r=8`
- 屏幕状态：测试时保持亮屏
- 温控约束：`TEMP_LIMIT_C=38.0`，`COOLDOWN_TEMP_C=37.0`
- 备注：GPU 脚本本轮未单独保存 idle baseline，因此表中只记录 active 窗口功率，不计算 baseline 增量

### 备注

- `tg128 r=3` 是短 Decode 测试，大多数 GPU 频点的自动窗口波动较高，因此这组主要作为吞吐趋势参考，不作为严格稳态功率结论。
- 原始 `342 MHz` 的 `tg128` sweep 实际窗口频率约 `828 MHz`，已废弃；表中使用 `/tmp/qwen15b-gpu-walt-tg128-r3-342-rerun-20260428` 的重测结果。
- `pp512` 的多个中低频点仍有较高功率窗口波动，后续如需精确稳态功率，建议增加 round 或按样本日志重算后段平台。
- 全部测试最高温度低于 `38 C`，最高约 `30.80 C`。
